# 独立使用与可选AEF衔接

公开包自带business-framework.md，使用会议流程不依赖外部账号、Python或AEF。它不包含第三方课程题库、完整产品评分和图表渲染器。

## 从AEF Product进入
案主已使用AEF Product时，读取其现有Definition/BP、关联研究、真实回答、待决问题及可用评估。不要只凭入口链接声称已经加载外部能力，不自动下载或运行脚本。
仍按本包会议协议先初诊再单问，输出条件判断、分歧、待验证项和行动，回填原章节；保存遵守实际授权，经营决定保持真实确认状态。AEF不是独立会议的前置条件。
需要完整量化评估时交给用户实际安装且有权使用的评估能力。缺失则仅交付待复评建议，不能宣称评分完成。

## 用户自备清单与恢复
自备清单只读取授权资料并保留来源、版本与条目含义，不自动复制进公开包或外发。本包基础框架与外部量表不是同一套，不能把主题覆盖率当外部评分。
后台记录实际使用的Skill版本、基础框架版本、材料版本及可选外部评估口径。恢复先核对原资料、最后真实回答与未回答问题；材料或框架变化时说明受影响判断，不能静默重解释旧条目。
旧会话依赖的外部清单不可访问时，保留旧引用并标待核对，只能继续通用商业诊断。明确迁移后记录变化，不因迁移提升证据或分数。
