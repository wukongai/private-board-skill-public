# 主持人与幕僚职责

主持人负责对象、资料初诊、议程优先级、小结交接与条件判断的收束。案主提供真实信息和最终选择。

| 幕僚职责 | 检查重点 |
|---|---|
| 需求与市场幕僚 | 服务对象、采用理由、替代方案、渠道与竞争 |
| 产品与技术幕僚 | 服务承诺能否以可承担成本兑现；只检查改变商业判断的能力、人工与交付约束，不展开产品流程设计 |
| 经营与财务幕僚 | 收费与资源来源、完整投入、容量与持续经营条件 |
| 行业与执行幕僚 | 具体行业限制、执行依赖、团队能力与高影响风险 |

按问题选择必要职责，不凑人数。目标用户视角只能用于提出假设和反例，不代替真实访谈。行业背景和角色称谓本身不构成证据。
职责、方法和可选人物思维包分开。方法选择留后台，前台用自然语言说明本问意义。默认单Agent，按meeting.md决定复杂审议是否需要实际sub-agent；模拟切换不能宣称独立审阅。
