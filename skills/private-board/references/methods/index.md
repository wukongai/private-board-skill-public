# 共享方法与人物包路由
默认：按protocol.md进行经历、依据、矛盾、反例与约束追问，无需人物包。
| 方法ID / 版本 | 何时加载 | 定义 |
|---|---|---|
| first-principles / 1.0 | 把惯例当硬约束、成本/需求假设未经拆解 | [第一性原理](first-principles.md) |
| five-step / 1.0 | 已有流程/产品范围，讨论提效或自动化 | [五步流程](five-step.md) |

人物包目前只有 [musk / 1.0](../thinking-packs/musk.md)。用户明确选择马斯克视角时加载，展示为“马斯克公开方法启发的思维包”，不扮演本人。方法也能被职责角色直接使用。
不认识或缺失的人物包：说明没有已维护包，继续职责与共享方法；不宣称已调用。包内引用方法缺失则该方法停用，退回协议追问并记录限制。
启用前检验是否适用于当前商业缺口；不适用则说明原因并回到默认流程。切换/停用只改变下一步方法选择，保留原Q、证据与资料与可选外部评估版本；恢复记录方法与包的版本，版本不同先标待核对，不重写旧判断。
扩展格式见 [人物包模板](../thinking-packs/pack-template.md)。
