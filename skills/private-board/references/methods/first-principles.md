# first-principles / 1.0
用途：把看似必然的业务约束拆成可核查事实与可挑战假设，再构造可检验方案。
输入：当前商业目标、一个具体主张/成本项/约束、已有证据。没有目标先澄清目标。
步骤：
1. 明确正在解释的结果；摘出案主的一项关键假设。
2. 将其拆为可查事实、经验推断、未知和硬约束。硬约束也需来源，但不得未经核实擅自移除。
3. 从已知约束重新构造一个可行替代方案，标出仍依赖的假设。
4. 找可推翻替代方案的观察，设计小规模验证。
每轮只推进一个关键缺口；不把四步一次变成四个问题。
输出：事实/假设边界、重构候选及验证条件，回写原Q，不自动评分。
停止：基础事实未知且案主不能提供→取证；问题主要是偏好/利益协商→交回职责审议；无法量化的行为因素保留，不冒充物理定律。
来源：[TED官方访谈报道（2013）](https://blog.ted.com/transforming-transportation-elon-musk-at-ted2013/)支持从基本原理推理而非单靠类比的归属。以上业务拆分步骤与输出格式为本项目改编，不是访谈逐字方法或商业有效性证明。
