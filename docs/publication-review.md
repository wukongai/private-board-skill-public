# 公开范围审查

## 可公开内容
本项目编写的主持流程、职责说明、商业议程、基础框架、会话模板、方法改编、使用文档和分发检查。公开方法保留原出处，第三方链接不纳入本项目授权范围。

## 排除内容
第三方课程清单及适配快照、付费角色包正文、私人会话与实际经营数据、内部任务台账、机器路径、候选缓存、原研发仓库Git历史。原研发库保持私有；本库从白名单文件建立全新历史，未以删除当前文件代替清理历史。

## 能力与验证边界
公开版可独立主持完整商业诊断会议；自带通用议题框架，不自称覆盖某第三方清单或完成AEF量化评分。量化评估由用户另行提供有权使用的能力。
发布前检查白名单、相对链接、路径与凭证特征、依赖缺失、压缩包文件一致性。行为场景为回归验收约束；未据此宣称完整真实效用已经验证。
