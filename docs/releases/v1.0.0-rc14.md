# v1.0.0-rc14 · 预发布候选

本轮从公开rc9定向同步共用主持控制与会议记录器，基础商业框架保持独立。公开包不含私有题库、vendor、购买原文、真实案主会话或本机路径。

```bash
npx skills add https://github.com/wukongai/private-board-skill-public/tree/v1.0.0-rc14 --skill private-board --agent codex
```

GitHub `/tree/v1.0.0-rc14` 地址固定该候选；`--skill`选择私董会，`--agent`选择宿主；Claude Code将codex换成claude-code。默认当前项目安装，需用户范围才加`--global`。发布tag后此命令可用。

主要变化：约定总预算与6轮检查点分离，有限续会明确批准，任务纠偏与切换；首问前及有实质变化当轮保存、阅读版与后台分离、唯一当前摘要；收口核对责任权限、行动窗口及停损处置。无Python仍可按协议主持并手工保存；未使用记录器须说明没有脚本结构校验。

公开包独立运行分发检查、记录器回归和隔离无AEF CLI smoke。它们检查文件边界和确定性保存行为，不是LLM完整会议效果测试。另行公开的长会话材料如来自私有研发版，将在其说明中标明来源；不得作为公开包实际长会话运行证明。

自动模拟已开展不等于人工验收。当前人工逐条验收尚未进行，真实用户效用、跨模型表现及商业结果未验证；保持prerelease，不称正式稳定版。
