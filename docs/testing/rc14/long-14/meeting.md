# 私董会会议纪要与执行方案

## 当前状态
讨论已收束；已用 14 / 15 次实质答复。
本场目标：栖链公司在7个工作日后提交90天一揽子经营决议，覆盖主攻客群、产品价格、渠道、存量履约、容量、激励、分批投资及进退条件。
当前判断与收束依据：本场提前收束：14/15答，已完成90天经营包的内部取舍、责任、首步和进退安排；尚不证明需求、付费、采用或盈利成立。顾悦3工作日汇总、第5日交叉核对、第6日CEO签、第7日董事会；容量合同现金未对齐不放行，附约未完成签署及准入未过不得启动。签字仅批小规模验证和首批上限，第二批须另审。

## 当前决议
- 原最多12次实质答复，第10答后案主明确批准增加3次至15；已用10不重算，每6次检查，足够提前收束。
- 只形成会议成果，不实施产品、合同、组织变更或外发。
- 90天主线为区域连锁标准订阅，实际启动2家30—120店同采购场景客户，第三家仅备选；优先现有5家共同异常链，排除3家复杂分摊。
- 小客户不列首批；供应商本季不收费；本季不做交易撮合抽佣。
- ERP仅为获客方式候选，不另建产品线；全国大客户存量承诺照履行，新增升级不能默认抢主线资源。
- 试点须有财务赞助人、区域运营负责人和2家核心供应商配合，每周联合复盘；缺少任一角色条件不启动。
- 销售主张为可验证的异常闭环，不承诺损耗下降或ROI。
- 标准年费18万元含80店、10供应商；初始化6万元；每多20店加年费3万元，供应商超额另评估不无限包。
- 首批8周试点每家4万元，首笔2万对应初始化、数据准入、可导出起始基线，第二笔2万对应中期完整报告与可用闭环；转年抵订阅不抵初始化，拒绝免费试点。己方第二段未交付则未收不收、已收退；首段未交付或越权致不能用退相应未交付部分，不能一概不退首笔。
- 服务限异常发现、双方确认、处理记录和对账证据导出；不代付款、不保证索赔、不撮合；客户可导出回到手工。
- 首年直接成本14.2万元（实施5.4、云支持2.8、客户成功3.6、销售2.4），直接毛利40.8%，不含研发；未来成本降至11.2万元才可能53.3%，续费成本预计7.6万元，均为预测。
- 工程180人日锁旧合同78、维修24；转型78为产品42、两家初始化16、权限导入验收8、应急12。产品设计60中旧20，转型32为两家试点16、价值评估8、培训8，余8缓冲，不填满。
- 交付周敏有权拒绝超容量；产品许禾负责标准范围；CEO最终裁决优先级；不增加自动付款或特制功能。
- 拒绝N客户70万元升级附带40人日、排他代码、全国最惠及先上后款90日条件；即便降至24日、50%预付、无排他，本季新增升级仍暂缓。N存量自定义结算继续支持6个月。
- 本季取消实际迁移5人日，仅保留迁移评估，实际迁移延至下季；未来仅自愿标准客户双轨4周并保留导出回退，复杂分摊客户留旧系统，不强迁不强涨价。
- 拒绝ERP本省独家2年、伙伴签客、30%佣金、永久免费接口、全量数据回传条件；仅接受非独家90天、新注册核实机会首年实收15%、无续费佣金、客户与栖链签、接口有支持上限超额报价、不给全量回传。伙伴不接受则暂停渠道。
- 首批2家直销试点及存量不向ERP付佣金；伙伴历史仅2条无决策人线索，不能当转化证明。
- 林舟负责两人直销不增员；乙丙两家、甲备选，180小时上限、每客30含全周期，活动池不另加；提交实际采购回款日历与统一报价。两家试点总合同额8万元、首笔合计4万元，年约不作确定收入。
- 林舟每周记实际销售工时，超180小时容量则减少推进对象；不向产品借人，不以加班隐去成本；甲保留候选但不拖住首批启动。
- 新线奖金从签约额8%当月发改为新实收对应4%售前发、另4%在首个闭环验证且无隐瞒承诺后发；旧已承诺奖金不追溯。
- 交付按范围兑现、真实工时、客户结果证据评价，不按上线数；超标准承诺须许禾与周敏共同签后CEO批准，林舟不得单独承诺。
- 顾悦组织跨销售产品交付每周30分钟经营复盘；CEO本周写规则并向销售合伙人解释，卢珊下次薪资周期执行。
- 首批管理投入48万元：研发交付内部成本30、外顾2、客户成功6、云测量4、销售试点4、应急2；其中内部折价32、增量现金16，固定工资已计185，现金表不重复计48。 按两家重算实际消耗，48仅首批上限，节省不填满。
- 第二阶段最多再24万元管理投入、8万元增量现金，必须验证门槛通过才批；剩48万元不承诺。
- 预计收款从160更正120，未投资预计现金510+120-185=445，首批增量16后429；卢珊每周监测投入现金、安全线240，不凭口头年约放款。
- 第二批仅在两家均达标且付清试点款、至少一家签正式年约后考虑，不能自动释放24万元。
- 每家至少20个真实异常全程可追；超48小时未处理比例相对各自4周基线下降30%；完整记录额外人工工时，不能用隐形人工达标；样本不足只记观察。
- 收集财务运营满意度但不替代指标，不以两家外推市场。乙丙为目标、甲备选；客户试点8周从签约、首笔到账及权限齐备起算，试点第4周闭环、第8周验收。乙争取季度第2周启动约第10周验收，丙第4周预算通过后才可能启动约第12周验收。
- 采购延迟则顺延观察，不自动延长本季投资许可、不拉甲凑数；两家结果齐备才可第二批审批，不凭乙一家过关提前扩张。
- 林舟取得实际采购节点，顾悦依客户启动日安排基线验收，对董事会呈现季度及客户试点两条时间线。
- 卢珊每周滚动监测现金和经济投入，预测低于240万元立即冻结新转型支出和承诺，保护已签旧合同；CEO48小时内决定缩减/退出及恢复，不等董事会。
- 顾悦汇总工时闭环、林舟管收款承诺、周敏看工程与老客SLA、陈砚看权限；工程预测超转型78人日即暂停新承诺，不偷挪旧线。
- 客户试点第4周无真实闭环不再加研发；季度第4周未有两家付费即停止新增承诺，只处理已签范围；试点第8周未过门槛不批24万元、终止扩展。
- 老客续约目标120万元若因资源抽离下降超过10%，顾悦报告并立即冻结新增扩展，由CEO调配。
- 失败客户按合同退未赚部分、导出数据并提供4周有限过渡，由顾悦周敏负责；不无限免费、不裁现有团队，容量回旧线盈利项目。
- 两家不可凭旧协议上线；本季完全不做跨客户训练和行业排名，不将供应商全量价表送共享模型；仅本客户权限内服务，供应商可查和导出自己的记录。
- 魏宁外顾10工作日出附约，费用2万元已在首批外顾项内；附约授权未签不启动；删除与留存按附约，不先承诺不存在时限。
- 陈砚周敏以样本导入对原始单、无越权、各方约定可见及导出结果验收，全部纳入8人日；做不到停其中一家或延期，不压安全、不开额外预算。
- 越权泄漏由陈砚立即停该客户，不等周会。
- 不采纳拟稿依据粉丝量立即全网投放和招聘渠道经理的建议；过去30条线索仅2条符合区域采购人且无付费，维持已定试点与不增员边界。
- 可用闭环业务验收为授权范围内真实异常可记录、双方确认、处理留痕、导出对账证据，不由后台人工偷偷补齐。
- 两段按约交付但经营ROI未达不因此退款；客户不参与先按约暂停，未交付部分不硬扣；4周过渡是退出支持上限，不能代替退款。
- 许禾顾悦记录验收事实，魏宁将产物与退款计算口径写合同并核条款，卢珊算未交付金额，争议CEO48小时裁决，保护客户与已签承诺，不等季末。
- 顾悦总牵头，3工作日收齐责任人版本，第5工作日交叉核对、第6天CEO签最终案、第7天董事会；第5日容量合同现金口径未齐不签放行，董事会拿条件案，不边上线边补。
- 魏宁附约10工作日完成，董事会只能附商务原则与待法律复核项，不写成已通过；授权条款未完成签署不得启动。CEO最终签字仅批准小规模验证和首批上限，不批准第二批、不等于商业成功。
